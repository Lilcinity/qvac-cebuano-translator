Speak Bisaya. Stay offline.

A private English–Cebuano translator that runs entirely on your device. No server call, no API key, nothing leaves this machine.

On-device Qwen3 1.7B via QVAC completion()
Ctrl/Cmd + Enter to translate

This is a low-resource language pair, so register and idiom handling can still vary between runs. Read more in the README.

Open source on GitHub. Powered by Tether's QVAC SDK.
